# ============================================================================
# ECOWOODS — ecowoodshardwood.com → ecowoods.ca
# Apache. Place as the ONLY .htaccess in the document root, on BOTH hosts.
# ============================================================================
#
# ONE HOP, ALWAYS. This is the whole design and it is the thing most versions
# of this file get wrong.
#
# The obvious way to write it is to force HTTPS first and then redirect the
# host. That produces:
#
#     http://www.old/x  →  https://www.old/x  →  https://ecowoods.ca/x
#
# Two redirects where one was needed. Every hop costs signal, adds latency on
# the slowest connections, and gives a crawler another chance to stop
# following. The rules below send every combination of scheme and host to the
# final URL in a single 301 — there is deliberately no HTTPS-forcing rule,
# because the destination is already https and forcing it first is what creates
# the chain.
#
# 301, not 302. A temporary redirect tells search engines to keep the OLD url
# indexed, which is the exact opposite of consolidating.
#
# Path-preserving. A link earned by /services/floor-refinishing passes to that
# page, not to a homepage the visitor then has to navigate. Redirecting
# everything to / is common and it discards most of the value.
#
# Query strings survive: Apache appends the original query string to a
# substitution that contains no "?" of its own. Do not add QSA — with R=301 it
# is already the behaviour, and adding it alongside an explicit "?" is how
# duplicated query strings happen.
# ============================================================================

<IfModule mod_rewrite.c>
  RewriteEngine On

  # Everything, from any host on this domain, in one hop.
  RewriteRule ^(.*)$ https://ecowoods.ca/$1 [R=301,L,NE]
</IfModule>

# Fallback for a server without mod_rewrite. mod_alias is compiled in almost
# everywhere mod_rewrite is not. RedirectMatch is also path-preserving.
<IfModule !mod_rewrite.c>
  <IfModule mod_alias.c>
    RedirectMatch permanent ^/(.*)$ https://ecowoods.ca/$1
  </IfModule>
</IfModule>

# No index file, no residual content, no robots.txt of its own. The redirect
# must fire before anything can be served. If an old index.html or index.php
# survives in this directory it will never be reached — but delete it anyway,
# so nobody restores a "temporary" homepage here in six months.
