# Deployment Guide — P0 Revenue Safety\n\n**Target:** Production deployment on Vercel  \n**Audience:** DevOps / Release Engineers  \n**Time estimate:** 10 minutes\n\n---\n\n## Pre-Deployment Checklist (Local)\n\n```bash\n# 1. Pull latest code\ngit pull origin main\n\n# 2. Install dependencies\npnpm install\n\n# 3. Run Prisma migrations (dev database)\npnpm exec prisma migrate dev\n\n# 4. Build locally to catch TypeScript errors\npnpm build\n\n# 5. Run a quick test\ncurl -X POST http://localhost:3000/api/pilot-leads \\\n  -H 'Content-Type: application/json' \\\n  -d '{\n    \"name\": \"Test User\",\n    \"email\": \"test@example.com\",\n    \"phone\": \"(555) 555-5555\",\n    \"companyName\": \"Test Co\",\n    \"role\": \"contractor\",\n    \"program\": \"floorforge-waitlist\"\n  }'\n# Expected: 201 response with pilotLeadId\n```\n\n---\n\n## Vercel Environment Setup\n\n### Option A: Via Vercel Dashboard\n\n1. Go to **Project → Settings → Environment Variables**\n2. Add or update these variables:\n\n**Database:**\n```\nDATABASE_URL = postgresql://user:pass@host/db\nDIRECT_URL = postgresql://user:pass@host/db  (Supabase only)\n```\n\n**Email (Resend):**\n```\nRESEND_API_KEY = re_xxxxxxxxxxxxxxxx\nRESEND_FROM_EMAIL = services@ecowoods.ca\nADMIN_EMAIL = admin@ecowoods.ca\n```\n\n**OR Email (SMTP):**\n```\nSMTP_HOST = smtp.gmail.com\nSMTP_PORT = 587\nSMTP_USER = noreply@ecowoods.ca\nSMTP_PASS = xxxx xxxx xxxx xxxx\nSMTP_FROM = noreply@ecowoods.ca\nADMIN_EMAIL = admin@ecowoods.ca\n```\n\n**Optional:**\n```\nPILOT_LEADS_WEBHOOK_URL = https://webhook.zapier.com/...\n```\n\n3. Set scope to **Production**\n4. Click **Save**\n\n### Option B: Via Vercel CLI\n\n```bash\n# Login to Vercel (if not already)\nvercel login\n\n# Set environment variables\nvercel env add DATABASE_URL\n# → paste postgresql://...\n\nvercel env add DIRECT_URL\n# → paste postgresql://...\n\nvercel env add RESEND_API_KEY\n# → paste re_xxxxxxxx\n\nvercel env add RESEND_FROM_EMAIL\n# → paste services@ecowoods.ca\n\nvercel env add ADMIN_EMAIL\n# → paste admin@ecowoods.ca\n\n# Verify\nvercel env list\n```\n\n---\n\n## Database Migration\n\n**Critical:** Must run migrations in production before deploying code.\n\n### Using Vercel Postgres (if applicable)\n\n```bash\n# Run migrations via Vercel\nvercel exec pnpm exec prisma migrate deploy\n\n# Verify\nvercel exec pnpm exec prisma db execute --stdin < <<< 'SELECT COUNT(*) FROM ecowoods.pilot_lead;'\n```\n\n### Using Supabase/Neon\n\n```bash\n# Option 1: Run migrations locally against production DB\nDATABASE_URL=\"postgresql://user:pass@host/db\" pnpm exec prisma migrate deploy\n\n# Option 2: Via Supabase dashboard\n# → SQL Editor → paste migration SQL (get from .prisma/migrations/)\n# → Run\n\n# Verify via psql\npsql $DATABASE_URL -c 'SELECT COUNT(*) FROM ecowoods.pilot_lead;'\n```\n\n**Expected output:**\n```\n (1 row) — shows table exists\n or\n \"0\" — shows table is empty (ready for data)\n```\n\n---\n\n## Deploy to Production\n\n### Option A: Via Git Push (Recommended)\n\n```bash\n# Commit changes\ngit add .\ngit commit -m \"P0: Production-safe pilot lead capture\"\n\n# Push to main\ngit push origin main\n\n# Vercel automatically deploys\n# Wait for build to complete (check Vercel dashboard)\n# → Deployments → watch for \"Ready\"\n```\n\n### Option B: Via Vercel CLI\n\n```bash\n# Deploy production build\nvercel --prod\n\n# Vercel will prompt for confirmation\n# → confirm and wait for deployment\n```\n\n---\n\n## Post-Deployment Verification\n\n### 1. Check Deployment Status\n\n```bash\n# Via Vercel CLI\nvercel ls\n\n# Via Vercel dashboard\n# → Deployments → latest should show \"Ready\" (green checkmark)\n```\n\n### 2. Test the API Endpoint\n\n```bash\n# Test pilot leads endpoint\ncurl -X POST https://ecowoods.ca/api/pilot-leads \\\n  -H 'Content-Type: application/json' \\\n  -d '{\n    \"name\": \"Prod Test User\",\n    \"email\": \"test@ecowoods.ca\",\n    \"phone\": \"(416) 555-1234\",\n    \"companyName\": \"Prod Test Co\",\n    \"role\": \"flooring-specialist\",\n    \"program\": \"floorforge-waitlist\"\n  }'\n\n# Expected:\n# HTTP 201\n# {\"success\": true, \"pilotLeadId\": \"pilot_...\", \"message\": \"Thank you...\"}\n```\n\n### 3. Verify Admin Email\n\n1. Submit test lead via API (see above) or FloorForge page\n2. Check ADMIN_EMAIL inbox within 10 seconds\n3. Should receive formatted email with lead details\n4. Click \"Review in Admin Portal\" → should link to /admin/pilot-leads/[id]\n\n### 4. Check Database\n\n```bash\n# Connect to production database\npsql $DATABASE_URL\n\n# List recent pilot leads\nSELECT id, name, email, company, role, created_at FROM ecowoods.pilot_lead \nORDER BY created_at DESC LIMIT 5;\n\n# Should show your test submission(s)\n```\n\n### 5. Test FloorForge Form\n\n1. Visit https://ecowoods.ca/products/floorforge\n2. Scroll to \"Join the Pilot Interest List\" button\n3. Click → modal opens\n4. Fill form with test data\n5. Submit\n6. Should see success toast: \"Thank you for your interest!\"\n7. Check admin email (same as step 3)\n\n### 6. Check Vercel Logs\n\n```bash\n# View production logs\nvercel logs\n\n# Filter for pilot lead events\nvercel logs | grep \"pilot.lead\"\n\n# Should see:\n# \"event\": \"pilot.lead.captured\" → indicates successful capture\n# \"event\": \"pilot.lead.db_persist_failed\" → if DB issues\n# \"event\": \"pilot.lead.email_failed\" → if email issues\n```\n\n### 7. Test Rate Limiting\n\n```bash\n# Submit 6 requests in rapid succession\nfor i in {1..6}; do\n  curl -X POST https://ecowoods.ca/api/pilot-leads \\\n    -H 'Content-Type: application/json' \\\n    -d '{\"name\": \"User '$i'\", \"email\": \"user'$i'@test.com\", \"phone\": \"(555) 555-555'$i'\", \"companyName\": \"Co '$i'\", \"role\": \"contractor\", \"program\": \"floorforge-waitlist\"}' \\\n    -w '\\nStatus: %{http_code}\\n'\ndone\n\n# Expected:\n# First 5: HTTP 201\n# 6th: HTTP 429 (rate-limited)\n```\n\n---\n\n## Rollback (If Issues)\n\n### Quick Rollback (via Vercel)\n\n```bash\n# List recent deployments\nvercel ls\n\n# Rollback to previous version\nvercel rollback [DEPLOYMENT_ID]\n\n# Verify (check Vercel dashboard)\n# → Deployments → latest should now show the previous version\n```\n\n### Code Rollback (via Git)\n\n```bash\n# Revert the P0 commit\ngit revert HEAD --no-edit\ngit push origin main\n\n# Vercel will redeploy (watch dashboard)\n```\n\n### Manual Rollback (last resort)\n\n```bash\n# Temporarily disable the endpoint by editing route.ts\n# Comment out POST handler, just return 503\n\n# Or comment out FloorForge integration\n# Change fetch URL back to /api/leads\n\n# Commit and push\ngit push origin main\n```\n\n---\n\n## Monitoring & Ongoing\n\n### Set Up Alerts\n\nIn Sentry, DataDog, or your monitoring tool:\n\n```\nERROR event:pilot.lead.db_persist_failed\n  → Page: true (critical)\n  → Email: devops@ecowoods.ca\n\nERROR event:pilot.lead.email_failed\n  → Page: false (warning only; not critical)\n  → Email: support@ecowoods.ca\n\n5xx errors on /api/pilot-leads\n  → Page: true\n  → Email: devops@ecowoods.ca\n\nHTTP 429 responses (rate-limited)\n  → Monitor for spikes (possible bot attacks)\n  → Threshold: >50 per hour\n```\n\n### Weekly Checks\n\n- [ ] Check Vercel Logs for any `pilot.lead.db_persist_failed` events\n- [ ] Verify admin email is receiving notifications\n- [ ] Sample database: `SELECT COUNT(*) FROM ecowoods.pilot_lead` (should grow)\n- [ ] Test FloorForge form submission (end-to-end)\n- [ ] Check admin portal can view recent leads\n\n---\n\n## Troubleshooting\n\n### 400 Bad Request\n```\nError: \"Please check the highlighted fields\"\n```\n→ Verify form field names match schema (name, email, phone, companyName, role, program)\n\n### 429 Too Many Requests\n```\nError: \"Too many requests. Please try again in a moment.\"\nretryAfter: 45\n```\n→ Rate limit hit; retry after 45 seconds (or wait 60s)\n\n### 500 Internal Server Error\n```\nCheck Vercel Logs:\n\"event\": \"pilot.lead.db_persist_failed\"\n```\n→ Database connection issue\n→ Verify DATABASE_URL is correct\n→ Check Supabase/Neon dashboard\n\n### Emails not sending\n```\nCheck Vercel Logs:\n\"event\": \"pilot.lead.email_failed\"\n```\n→ Verify RESEND_API_KEY or SMTP_* are set\n→ For Resend: check API dashboard (rate limits, errors)\n→ For SMTP: verify credentials and firewall (port 587/465)\n\n### Database migrations not applied\n```\nError in logs: \"relation ecowoods.pilot_lead does not exist\"\n```\n→ Run: `vercel exec pnpm exec prisma migrate deploy`\n→ Or manually run SQL migration\n\n---\n\n## Checklist for Sign-Off\n\nBefore marking P0 complete:\n\n- [ ] Code deployed to production\n- [ ] All environment variables set (DATABASE_URL, RESEND_API_KEY or SMTP_*, ADMIN_EMAIL)\n- [ ] Database migrations applied\n- [ ] API test returns 201\n- [ ] Admin email received for test submission\n- [ ] FloorForge form works end-to-end\n- [ ] Vercel logs show \"event: 'pilot.lead.captured'\"\n- [ ] Alerts configured in monitoring tool\n- [ ] Team notified of new endpoint\n- [ ] Documentation accessible (README, PRODUCTION_ENV_CHECKLIST, etc.)\n\n---\n\n**Deployment Time:** ~10 minutes  \n**Downtime:** None (rolling deploy)  \n**Rollback Time:** ~2 minutes (if needed)\n\n---\n\n**Questions?** See P0_REVENUE_SAFETY_REPORT.md or PRODUCTION_ENV_CHECKLIST.md\n"
