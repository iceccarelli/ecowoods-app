these fields are present and correctly typed\nconst schema: Article = buildArticle({\n  id: string;          // required\n  headline: string;    // required\n  description: string; // required\n  author: Person;      // required, typed\n  publishedAt: Date;   // required, typed\n  // ... optional fields\n});\n\n// If you pass wrong type, TypeScript errors before build\n```\n\n### Composition Pattern\n\nEach builder is a pure function:\n\n```typescript\n// Take config → return valid JSON-LD\nconst schema = buildOrganization(ROOT_ORG_CONFIG);\nconst schema = buildArticle(articleConfig);\nconst schema = buildProduct(productConfig);\n```\n\n### No Runtime Cost\n\n- Schemas built at **build time**, not per-request\n- No database queries\n- JSON-LD strings
