## 2. Exact P0 Actions Required for Revenue Safety

**Execute these in order. Each is a distinct blocking task.**

### P0.1 — Database (Highest Priority)
**Objective:** Persist leads to a real PostgreSQL database  
**Why:** Without this, database outages silently drop leads (logs persist, but no structured data).

**Action:**
1. Create a Supabase or Neon account (both have free tiers)
   - **Supabase:** supabase.com → New project
   - **Neon:** neon.tech → Free tier, excellent for serverless
2. Get the connection string (PostgreSQL URI format)
3. Set in Vercel **Project Settings → Environment Variables**:
   ```
   DATABASE_URL = postgresql://user:pass@host:port/dbname
   DIRECT_URL = postgresql://user:pass@host:port/dbname
   ```
4. Run migration:
   ```bash
   pnpm --filter @ecowoods/web db:push
   ```
5. **Verify:** Submit a test lead form → should appear in Supabase `ecowoods.quote_requests` table

**Success metric:** Lead captured in DB within 2 seconds of form submission  
**Estimated effort:** 20 minutes

---

### P0.2 — Email Admin Notification (Second Priority)
**Objective:** Owner receives email notification for every lead within 5 seconds  
**Why:** Without this, leads sit unactioned; owner has no way to prioritize.

**Option A: Resend (Recommended)**
1. Sign up at resend.com (free: 3,000 emails/month)
2. For dev/test: use `onboarding@resend.dev` as FROM email (no domain verification needed)
3. Get API key from Resend → API Keys
4. Set in Vercel:
   ```
   RESEND_API_KEY = re_xxxxxxxxxxxxx
   RESEND_FROM_EMAIL = onboarding@resend.dev  (or your domain when verified)
   ADMIN_EMAIL = owner@ecowoods.ca
   ```
5. **Verify:** Submit test lead → check owner inbox in 5 seconds

**Option B: Gmail SMTP (Fallback)**
1. Google Account → Security → 2-Step Verification (turn ON)
2. Google Account → Security → App Passwords → create one (Mail + Other)
3. Copy the 16-character password
4. Set in Vercel:
   ```
   SMTP_HOST = smtp.gmail.com
   SMTP_PORT = 587
   SMTP_USER = your.gmail@gmail.com
   SMTP_PASS = xxxx xxxx xxxx xxxx
   SMTP_FROM = your.gmail@gmail.com
   ADMIN_EMAIL = owner@ecowoods.ca
   ```

**Success metric:** Admin receives formatted email with lead details within 5 s  
**Estimated effort:** 15 minutes (Resend) or 20 minutes (Gmail)

### P0.5 — Rate Limiting (Fifth Priority)
**Objective:** Prevent spam on `/api/leads`  
**Why:** Anyone can submit unlimited lead forms; CAPTCHA + rate limit are essential.

**Action:**
1. Add `@upstash/ratelimit` package:
   ```bash
   pnpm add @upstash/ratelimit --filter @ecowoods/web
   ```
2. Create Upstash account (upstash.com) → Redis database (free tier)
3. Get REST URL + token
4. Add rate limit to `apps/web/app/api/leads/route.ts`:
   ```typescript
   import { Ratelimit } from '@upstash/ratelimit';
   import { headers } from 'next/headers';

   const ratelimit = new Ratelimit({
     redis: Redis.fromEnv(),
     limiter: Ratelimit.slidingWindow(5, '1 h'), // 5 leads per hour per IP
   });

   export async function POST(request: Request) {
     const ip = headers().get('x-forwarded-for') || 'unknown';
     const { success } = await ratelimit.limit(ip);
     
     if (!success) {
       return NextResponse.json(
         { success: false, message: 'Too many requests. Please try again later.' },
         { status: 429 }
       );
     }
     // ... rest of handler
   }
   ```
5. **Also add honeypot field** to form (hidden input that should stay empty)

**Success metric:** Submitting >5 leads per hour returns 429 (Too Many Requests)  
**Estimated effort:** 25 minutes

### P0.6 — Web CI/CD
**Objective:** Automated tests + build validation for Next.js app  
**Why:** Current CI only tests Python backend; web app can deploy broken code.

**Action:**
1. Add workflow `.github/workflows/web-ci.yml`:
   ```yaml
   name: Web CI
   on:
     push:
       branches: [main]
     pull_request:
       branches: [main]
   
   jobs:
     typecheck:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with:
             node-version: '18'
         - run: corepack enable && pnpm install
         - run: pnpm --filter @ecowoods/web typecheck
   
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with:
             node-version: '18'
         - run: corepack enable && pnpm install
         - run: TURBO_FORCE=true pnpm build
   
     smoke-test:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - uses: actions/setup-node@v4
           with:
             node-version: '18'
         - run: corepack enable && pnpm install
         - run: pnpm --filter @ecowoods/web add -D @playwright/test
         - run: pnpm exec playwright install
         - run: |
             pnpm --filter @ecowoods/web dev --port 3000 &
             sleep 5
             pnpm --filter @ecowoods/web exec playwright test e2e/quote-form.spec.ts
   ```
2. Add simple Playwright test for quote form submission to `apps/web/e2e/quote-form.spec.ts`

**Success metric:** CI blocks PRs with typecheck/build/test failures  
**Estimated effort:** 45 minutes
