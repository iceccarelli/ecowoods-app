# Proof sliders — pack 02

Unzip at the **repository root** of `ecowoods-app`. Complements pack 01 (pairs 01–08). Does not overwrite those files.

```
unzip ecowoods-slider-pack-02.zip
```

Writes:

```
apps/web/public/images/sliders/09-* … 16-*
docs/visual/SLIDER_PACK_02.md
```

Every pair is **1920×1280**, 3:2, sRGB. Use `.webp` on the site. Keep `.jpg` as masters.

These are **illustrations**, not job photographs. Register as `kind: 'illustration'` only.

Public URL once deployed:

```
https://ecowoods.ca/images/sliders/<filename>
```
