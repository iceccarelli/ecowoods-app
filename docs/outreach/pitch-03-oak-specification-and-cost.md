# Pitch 03 — what a hardwood quote is actually made of

**Targets:** personal-finance and home-economics desks, real-estate
aggregators, renovation-cost verticals, design blogs that run buyer guides.

**Why this angle lands:** everyone publishes a price range and nobody publishes
the mechanism. We publish both, with the commodity inputs live from the Bank of
Canada — which is a data story, and data stories get linked.

**What we can put behind it:**

- `/market` — forestry, energy and USD/CAD, pulled live from the Bank of Canada,
  with the mechanism behind each and why it is volatile
- `/api/market` — the same data as JSON, CORS-open, no key
- `/guides/how-to-evaluate-a-hardwood-quote` — the published criteria
- `/framework/assess` — score any quote, from anyone
- Price bands: `/services`, published as full bands rather than starting-from
  numbers

**Note before sending:** the ROI framing in the original brief — premium oak
versus builder-grade, as a resale return — needs a source we do not have. Do not
assert a resale figure. The version below makes the cost-mechanism argument
instead, which is the part we can actually evidence.
