# JSON-LD Schema Implementation Guide\n**EcoWoods Entity Graph & Structured Data System**\n\n**Status:** Production-ready | **Date:** July 31, 2026 | **Architect:** Lead Technical\n\n---\n\n## Overview\n\nThe new schema system (`apps/web/lib/schema/`) provides production-grade JSON-LD structured data that AI agents and search engines use to understand EcoWoods.\n\nEvery page emits **three root schemas** automatically:\n1. **Organization** (LocalBusiness + 6 nested Services)\n2. **WebSite**\n3. **FAQPage** (homepage questions)\n\nAdditional schemas (Article, CaseStudy, Product, Breadcrumb) can be added per-page.\n\n---\n\n## What Changed\n\n### Files Created\n```\napps/web/lib/schema/\n├── types.ts              (20+ TypeScript interfaces for all schema types)\n├── builders.ts           (type-safe schema constructors)\n├── root-schema.ts        (ROOT_ORGANIZATION_SCHEMA, ROOT_WEBSITE_SCHEMA, etc.)\n├── components.tsx        (React components for page-level schemas)\n├── utils.ts              (serialization, validation, cleaning)\n└── index.ts              (unified public API + backward compatibility)\n```\n\n### Files Modified\n```\napps/web/app/layout.tsx\n  - Removed: import from lib/structured-data\n  - Added: import from lib/schema\n  - Updated: injected ROOT_ORGANIZATION_SCHEMA, ROOT_WEBSITE_SCHEMA, HOMEPAGE_FAQ_SCHEMA\n```\n\n---\n\n## Root Schema (Injected on Every Page)\n\n### What Gets Emitted\n\nEvery page's `<head>` now contains three `<script type=\"application/ld+json\">` tags:\n\n#### 1. Organization Schema\n```json\n{\n  \"@context\": \"https://schema.org\",\n  \"@type\": [\"LocalBusiness\", \"HomeAndConstructionBusiness\"],\n  \"@id\": \"https://ecowoods.ca/#organization\",\n  \"name\": \"Ecowoods Inc.\",\n  \"legalName\": \"Ecowoods Hardwood Flooring Inc.\",\n  \"url\": \"https://ecowoods.ca\",\n  \"telephone\": \"+1-647-244-5156\",\n  \"email\": \"services@ecowoods.ca\",\n  \"address\": { ... postal address ... },\n  \"geo\": { \"@type\": \"GeoCoordinates\", \"latitude\": 43.72085, \"longitude\": -79.57542 },\n  \"areaServed\": [ { \"@type\": \"City\", \"name\": \"Toronto\" }, ... 15 cities total ... ],\n  \"openingHoursSpecification\": [ ... Mon-Sat 8am-7pm, Sun 10am-4pm ... ],\n  \"service\": [ ... 6 nested Service objects ... ]\n}\n```\n\n#### 2. Website Schema\n```json\n{\n  \"@context\": \"https://schema.org\",\n  \"@type\": \"WebSite\",\n  \"@id\": \"https://ecowoods.ca/#website\",\n  \"url\": \"https://ecowoods.ca\",\n  \"name\": \"Ecowoods\",\n  \"inLanguage\": \"en-CA\",\n  \"publisher\": { \"@id\": \"https://ecowoods.ca/#organization\" }\n}\n```\n\n#### 3. FAQ Schema\n```json\n{\n  \"@context\": \"https://schema.org\",\n  \"@type\": \"FAQPage\",\n  \"mainEntity\": [\n    {\n      \"@type\": \"Question\",\n      \"name\": \"Is the estimate really fixed?\",\n      \"acceptedAnswer\": { \"@type\": \"Answer\", \"text\": \"Yes...\" }\n    },\n    ... 3 more questions ...\n  ]\n}\n```\n\n---\n\n## Nested Services\n\nThe Organization schema includes Installation\",\n    \"description\": \"Solid and engineered hardwood...\",\n    \"areaServed\": [\"Toronto\", \"North York\", \"Markham\", \"Mississauga\"],\n    \"offers\": {\n      \"@type\": \"Offer\",\n      \"priceCurrency\": \"CAD\",\n      \"priceRange\": \"$4,000–$15,000\",\n      \"availability\": \"PT10M\"\n    }\n  },\n  ... 5 more services (Refinishing, Dust-Free Sanding, Blog Article\n\n**File:** `apps/web/app/blog/[slug]/page.tsx`\n\n```typescript\nimport { buildArticle, SchemaScript } from '@/lib/schema';\n\nexport const generateMetadata = async ({ params }: Props) => {\n  const article = await fetchArticle(params.slug);\n  return {\n    title: article.headline,\n    description: article.description,\n  };\n};\n\nconst ArticlePage = async ({ params }: Props) => {\n  const article = await fetchArticle(params.slug);\n\n  const schema = buildArticle({\n    id: params.slug,\n    headline: article.headline,\n    description: article.description,\n    content: article.body,\n    author: { name: 'Mark Carelli', title: 'Lead Architect' },\n    publishedAt: new Date(article.publishedAt),\n    wordCount: article.wordCount,\n    readingTimeMinutes: Math.ceil(article.wordCount / 200),\n    imageUrl: article.imageUrl,\n    siteUrl: process.env.NEXT_PUBLIC_SITE_URL,\n    topics: article.topics,\n  });\n\n  return (\n    <>\n      <SchemaScript schema={schema} />\n      {/* article content */}\n    </>\n  );\n};\n```\n\n### Example 2: Case Study\n\n**File:** `apps/web/app/case-study/[slug]/page.tsx`\n\n```typescript\nimport { buildCaseStudy,
