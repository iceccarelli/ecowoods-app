# Production Environment Checklist — EcoWoods Revenue Safety\n\n**Audience:** DevOps / Deployment Engineers  \n**Goal:** Verify all environment variables are correctly set before deploying lead capture.  \n**Status Required:** ✅ All items checked before production deployment\n\n---\n\n## Database\n\n- [ ] **DATABASE_URL** — PostgreSQL connection string (Supabase or Neon)\n  - Format: `postgresql://user:password@host:5432/dbname`\n  - Verify with: `psql $DATABASE_URL -c \"SELECT version();\"` (should connect without error)\n  - Test for lead capture: Can insert to `ecowoods.pilot_lead` table\n\n- [ ] **DIRECT_URL** — Direct connection (Supabase only; used for migrations)\n  - Only needed if using Supabase connection pooling\n  - Same as DATABASE_URL if using connection pooling\n  - Verify: `psql $DIRECT_URL -c \"SELECT COUNT(*) FROM ecowoods.pilot_lead;\"`\n\n- [ ] **Prisma Migrations Deployed**\n  ```bash\n  pnpm exec prisma migrate deploy\n  # Should show: \"✔ Your database is now in sync with your schema\"\n  ```\n\n---\n\n## Email (Choose One)\n\n### Option A: Resend (Recommended)\n\n- [ ] **RESEND_API_KEY** — Get from [resend.com/api-keys](https://resend.com/api-keys)\n  - Format: `re_xxxxxxxxxxxxx` (starts with `re_`)\n  - Test: `curl -s -X POST 'https://api.resend.com/emails' -H 'Authorization: Bearer $RESEND_API_KEY' | grep -q '\"message\"'` → should have a message\n\n- [ ] **RESEND_FROM_EMAIL** — Email address or `onboarding@resend.dev`\n  - Dev: `onboarding@resend.dev` (no domain verification needed)\n  - Prod: `services@ecowoods.ca` or similar (requires domain verification in Resend dashboard)\n  - If using custom domain:\n    - Add domain in Resend dashboard\n    - Add SPF, DKIM, DMARC DNS records\n    - Wait for verification (5–15 minutes)\n\n- [ ] **ADMIN_EMAIL** — Recipient for all admin notifications\n  - Format: `admin@ecowoods.ca` or your notification email\n  - Must be able to receive emails from `RESEND_FROM_EMAIL`\n  - Test: Submit a test lead; check that admin email receives notification\n\n### Option B: SMTP (Gmail, etc.)\n\n- [ ] **SMTP_HOST** — e.g., `smtp.gmail.com`\n- [ ] **SMTP_PORT** — e.g., `587` (TLS) or `465` (SSL)\n- [ ] **SMTP_USER** — Full email address (e.g., `noreply@ecowoods.ca`)\n- [ ] **SMTP_PASS** — App password (NOT your regular password)\n  - For Gmail: Generate at [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)\n  - 2-Step Verification must be enabled\n  - Format: 16 characters (spaces OK)\n- [ ] **SMTP_FROM** — Sender address (e.g., `noreply@ecowoods.ca`)\n- [ ] **Dependency Installed**: `pnpm add nodemailer @types/nodemailer --filter @ecowoods/web`\n\n---\n\n## Optional: Pilot Lead Webhook (CRM Integration)\n\n- [ ] **PILOT_LEADS_WEBHOOK_URL** — Optional; forwards leads to Zapier, n8n, Make, etc.\n  - Format: `https://webhook.example.com/path`\n  - If not set, skipped (no error)\n  - Test: Submit a lead; webhook should receive POST with pilotLeadId, name, email, etc.\n  - Common targets:\n    - Zapier: `https://hooks.zapier.com/hooks/catch/xxxxx/xxxxx/`\n    - n8n: `https://your-n8n.example.com/webhook/pilot-leads`\n    - Make: `https://hook.integromat.com/xxxxx/pilot-leads`\n\n---\n\n## Verification Steps\n\n### 1. Production Deployment\n\n#### Vercel Dashboard\n\n1. Go to Project → Settings → Environment Variables\n2. app password is correct\n- Check Vercel Logs for `pilot.lead.email_failed`\n- Test: `curl -X POST https://api.resend.com/emails ... -H \"Authorization: Bearer $RESEND_API_KEY\"`\n\n### Admin emails landing in spam\n- **Resend:** Add SPF, DKIM, DMARC records (Resend dashboard)\n- **Gmail:** Check spam folder; mark as \"Not Spam\"\n- **Custom domain:** Ensure domain is verified in email service\n\n---\n\n## Quick Reference\n\n| Variable | Required | Example | Where |\n|----------|----------|---------|-------|\n| `DATABASE_URL` | ✅ | `postgresql://...` | Supabase/Neon |\n| `DIRECT_URL` | ⚠️ | `postgresql://...` | Supabase (connection pooling) |\n| `RESEND_API_KEY` | ⚠️ | `re_xxxxx` | resend.com/api-keys |\n| `RESEND_FROM_EMAIL` | ⚠️ | `services@ecowoods.ca` | Resend dashboard |\n| `SMTP_HOST` | ⚠️ | `smtp.gmail.com` | Email provider |\n| `SMTP_USER` | ⚠️ | `noreply@ecowoods.ca` | Email provider |\n| `SMTP_PASS` | ⚠️ | `xxxx xxxx xxxx xxxx` | Email provider (app password) |\n| `ADMIN_EMAIL` | ✅ | `admin@ecowoods.ca` | Your team |\n| `PILOT_LEADS_WEBHOOK_URL` | ❌ | `https://webhook.zapier.com/...` | CRM/automation (optional) |\n\n**✅ = Required**  \n**⚠️ = Pick one option (Resend OR SMTP)**  \n**❌ = Optional**\n\n---\n\n## Post-Deployment Monitoring\n\nAdd these alerts in Sentry/DataDog/Vercel:\n\n```\nERROR event:pilot.lead.db_persist_failed → Page: true\nERROR event:pilot.lead.email_failed → Page: false (best-effort, alert after 5+ failures)\n5xx /api/pilot-leads → Page: true\n```\n\n---\n\n**Last Updated:** 2026-08-06  \n**Questions?** See `P0_REVENUE_SAFETY_REPORT.md`\n"
